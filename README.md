# 달토끼의 당근 모으기

유아를 위한 터치 기반 채소 수집 게임입니다. 당근과 오이를 토끼에게 모아 주면 친구들이 등장하고, 채소 14개를 모으면 모두 함께 달로 날아갑니다.

## 실행

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버를 사용하려면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8000>에 접속합니다. 큰 **같이 놀기** 버튼을 누르면 게임과 오디오가 시작됩니다.

## 현재 구현

- 안경을 쓴 토끼와 친구 12종: 거북이, 분홍 오징어, 빨간 고양이, 빨간 오리, 노랑 병아리, 파란 펭귄, 사자, 호랑이, 여우, 말레이곰, 불곰, 삵.
- 토끼가 “당근 2개 주세요”처럼 구체적으로 부탁합니다. 목표 채소 그림과 필요한 수량을 계속 보여 주며, 하나가 도착할 때 그림 하나를 채우고 “하나 줬어요”라고 알려 줍니다.
- 첫 부탁은 당근 한 개만 보여 주어 조작을 익힙니다. 다음부터는 당근·오이 중 부탁한 채소를 고릅니다. 다른 채소를 눌러도 진행을 잃거나 경고음이 나지 않고, 올바른 선택지에 차분한 테두리 힌트를 보여 줍니다.
- 부탁은 당근 1개 → 오이 2개 → 당근 3개 → 오이 2개 → 당근 3개 → 오이 3개입니다. 1~3개의 수량을 연습하며 전체 14개 목표는 유지합니다. 한 번에 하나씩 주고, 부탁을 마치면 1.8초 동안 완성된 그림을 보여 준 뒤 다음 부탁으로 넘어갑니다.
- 선택지는 목표 그림·달·친구와 겹치지 않게 배치합니다. 공간이 좁으면 부탁한 채소를 우선해 수집이 막히지 않게 합니다.
- 요청한 채소의 그림·이름과 터치한 동물 이름을 보여 줍니다. 동물을 눌러도 부탁 문구는 유지합니다. 보호자와 함께 세고 이야기할 수 있으며, 실패·벌점·시간제한은 없습니다.
- 매 게임 친구 등장 순서를 섞고, 채소 1개부터 12개까지 모을 때마다 한 명씩 등장합니다. 모든 친구를 매 판 만납니다.
- 채소 14개 도착 시 1.2초 후 엔딩을 시작합니다. 엔딩은 `arc`, `spiral`, `bounce`, `float` 중 무작위로 선택하며 비행 뒤 3초 동안 함께 기뻐합니다.
- 캐릭터 터치 반응, 달 터치 시 화면 어두워짐, 절차적 효과음과 자장가 배경음악을 지원합니다.
- 사자를 터치하면 갈기를 흔들며 작은 소리를 내고 하트를 뿌립니다. 호랑이를 터치하면 폴짝 뛰며 별을 뿌립니다.
- 여우는 큰 귀와 하얀 꼬리 끝이 특징이며, 터치하면 꼬리를 흔들고 하트를 뿌립니다.
- 말레이곰은 짙은 털과 밝은 가슴 무늬, 항상 내민 분홍 혀가 특징입니다. 터치하면 혀를 더 길게 내밀고 흔들며 하트를 뿌립니다.
- 불곰은 갈색 털과 둥근 귀·큰 앞발이 특징이며, 터치하면 앞발을 흔들고 하트를 뿌립니다. 삵은 점박이 털과 고리무늬 꼬리가 특징이며, 터치하면 꼬리를 흔들고 별을 뿌립니다.
- 친구는 두 줄로 배치합니다. 엔딩에서는 확대된 달과 친구의 공간을 쉬기·다시 놀기 패널과 분리하고, 비행과 착륙 위치를 화면 안으로 제한합니다.
- 친구가 늘어나도 잘 보이도록 줄별 인원에 맞춰 크기를 조절하고, 작은 화면에서는 두 줄 사이 간격을 확보합니다.
- 채소 터치 영역을 넓히고 친구의 현재·도착 위치와 다른 채소를 피해 생성합니다. 마지막 채소를 모은 후 추가 수집과 생성을 멈춥니다.
- 오른쪽 위 **잠깐 쉬기** 또는 Escape 키로 움직임·게임 시간·음악을 함께 멈추고, **계속 놀기**로 이어갑니다. 다른 탭으로 이동하면 자동으로 쉬며, 돌아와도 직접 계속하기 전까지 기다립니다.
- 소리 버튼으로 배경음악과 효과음을 함께 켜거나 끕니다. 선택은 브라우저 저장소에 보관하며, 저장소를 사용할 수 없어도 현재 놀이에서는 작동합니다.
- 효과음의 겹침과 음량을 줄이고, 파티클을 최대 48개로 제한합니다. 시스템의 움직임 줄이기 설정을 반영하며, 화면 주사율에 따른 효과 속도 차이를 줄였습니다.
- 엔딩에서는 **이제 쉬기**로 처음 화면에 돌아가거나 **다시 놀기**로 친구 순서를 새로 섞습니다. 화면 아무 곳이나 눌러도 재시작하지 않습니다. 주변의 초록색을 찾아보는 화면 밖 놀이도 제안합니다.
- 고해상도 화면은 최대 2배 해상도로 그리며, 터치와 배치는 화면의 CSS 픽셀 좌표를 사용합니다.

Canvas 2D와 Web Audio API를 사용하는 순수 JavaScript 프로젝트입니다. 외부 패키지, 이미지·음원 파일, 빌드 단계는 없습니다.

## 검증

저장소 루트에서 Node.js가 있다면 실행합니다.

```sh
node tests/game-smoke.js
```

macOS에서는 별도 설치 없이 JavaScriptCore로 실행할 수도 있습니다.

```sh
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc tests/game-smoke.js
```

회귀 검사는 문법, 엔딩 4종 × 화면 크기 7종의 28개 조합, 친구 12종, 부탁한 종류·수량과 힌트, 쉬기·재개·재시작·화면 회전, 오디오 생명주기·소리 저장 예외, 고해상도 입력·움직임 설정·파티클을 확인합니다. 최신 부탁 흐름으로 JavaScriptCore 회귀 검사와 실제 WebKit 15개 시나리오가 통과했습니다. 상세 실행 결과는 `.continue-here.md`의 현재 구현 절에 기록합니다. Canvas와 Audio를 모의 API로 실행하는 검사와 실제 브라우저의 화면 검증을 구분하며, 완료한 항목과 남은 제약은 `.continue-here.md`에 기록합니다.

외부 자료에 근거해 수량·이름 탐색과 공동 놀이를 돕도록 설계했습니다. 학습효과나 실제 아이의 선호를 검증한 것은 아닙니다.
