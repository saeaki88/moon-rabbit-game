# 달토끼의 당근 모으기

유아를 위한 터치 기반 채소 수집 게임입니다. 당근과 오이를 토끼에게 모아 주면 친구들이 등장하고, 채소 14개를 모으면 모두 함께 달로 날아갑니다.

## 실행

[웹에서 바로 놀기](https://saeaki88.github.io/moon-rabbit-game/)를 열고 큰 **같이 놀기** 버튼을 누릅니다. 별도 설치나 빌드 없이 `index.html`을 브라우저에서 열 수도 있습니다. 로컬 서버를 사용하려면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8000>에 접속합니다. 큰 **같이 놀기** 버튼을 누르면 게임과 오디오가 시작됩니다.

## 현재 구현

- 안경을 쓴 토끼와 친구 12종: 거북이, 분홍 오징어, 빨간 고양이, 빨간 오리, 노랑 병아리, 파란 펭귄, 사자, 호랑이, 여우, 말레이곰, 불곰, 삵.
- 토끼 그림 옆에 필요한 채소를 1~3개, 큰 그림으로 보여 줍니다. 목표 그림은 항상 원래 색을 유지하고, 하나가 도착할 때마다 그림 하나에 체크를 붙입니다. 한글이나 숫자를 읽지 않아도 같은 그림 찾기와 하나씩 주기를 따라갈 수 있도록 구성했습니다.
- 첫 부탁은 당근 한 개만 보여 주고, 손가락 그림으로 제자리에서 누르는 동작을 짧게 보여 줍니다. 다음부터는 당근·오이 중 부탁한 채소를 고릅니다. 다른 채소를 누르면 벌점·경고음 없이 올바른 선택지의 테두리와 손가락 시범을 2.8초 보여 줍니다.
- 왼쪽 위 부탁 그림판을 누르면 손가락 시범을 다시 볼 수 있습니다. 시작 화면도 채소 누르기 → 토끼에게 전달하기 그림으로 안내하며, 시작·계속·쉬기·다시 놀기에는 큰 아이콘을 함께 사용합니다.
- 부탁은 당근 1개 → 오이 2개 → 당근 3개 → 오이 2개 → 당근 3개 → 오이 3개입니다. 1~3개의 수량을 연습하며 전체 14개 목표는 유지합니다. 한 번에 하나씩 주고, 부탁을 마치면 1.8초 동안 완성된 그림을 보여 준 뒤 다음 부탁으로 넘어갑니다.
- 선택지는 목표 그림·달·친구와 겹치지 않게 배치합니다. 공간이 좁으면 부탁한 채소를 우선해 수집이 막히지 않게 합니다.
- 높이가 충분한 화면에서는 부탁 문구와 “하나 줬어요”·동물 이름을 보조로 표시합니다. 높이 480px 이하에서는 부탁 그림판에 토끼·채소·체크만 남깁니다. 동물을 눌러도 목표 그림은 유지하며, 실패·벌점·시간제한은 없습니다.
- 소리가 켜져 있고 브라우저가 한국어 음성을 지원하면 “당근 한 개 줄래?” 같은 부탁과 “하나, 둘, 셋”을 읽어 줍니다. 이름·식별자에 고품질 표시가 있는 목소리를 먼저 선택하고, 같은 우선순위에서는 로컬 목소리를 우선합니다. 이는 표시를 이용한 추정으로 실제 음질은 기기와 설치된 목소리에 따라 달라집니다. 일부 브라우저 목소리는 네트워크가 필요할 수 있습니다. 부탁 그림판을 누르면 현재 부탁을 다시 읽습니다. 음성이 지원되지 않거나 재생에 실패해도 그림 안내로 계속 놀 수 있습니다. 앱에서 별도 API 키·유료 음성 서비스·마이크를 사용하지 않습니다.
- 토끼나 달 속 토끼를 누르면 “오이 두 개 찾아 줄래?”처럼 남은 채소를 부탁합니다. 일부를 건넸다면 “오이 한 개 더 찾아 줄래?”, 부탁을 막 마쳤다면 “고마워”라고 말합니다. 소리가 없어도 목표 채소에 2.8초 그림 시범을 보여 줍니다. 완료 직후 감사 반응은 다음 부탁까지 1.8초, 마지막 엔딩까지 1.2초의 기다림을 터치 시점부터 다시 줍니다.
- 친구 12종은 각각 인사·다정한 말·자기 특징을 담은 대사 4개 중 하나를 무작위로 말하며, 같은 친구의 직전 대사는 바로 반복하지 않습니다. 대사만 동물마다 달라지고 목소리 엔진과 음색 설정은 같습니다. 수 세기·전달·부탁 완료 안내와 겹치지 않게 짧게 쉬어 말하며, 채소 목표와 점수는 바꾸지 않습니다.
- 첫 화면의 **보호자 · 이름 불러주기**를 펼쳐 이름이나 별명을 저장하거나 지울 수 있습니다. 이름은 선택 사항이며 이 브라우저에만 저장합니다. 저장소가 차단되면 현재 놀이에서만 사용합니다. 입력한 이름을 부르는 음성에는 기기의 로컬 한국어 목소리만 사용하고, 없으면 음성에서는 “친구야”로 부릅니다. 화면에는 설정한 호칭을 유지하며 입력값을 서버·URL·공개 코드에 넣지 않습니다.
- 매 게임 친구 등장 순서를 섞고, 채소 1개부터 12개까지 모을 때마다 한 명씩 등장합니다. 모든 친구를 매 판 만납니다.
- 채소 14개 도착 시 1.2초 후 엔딩을 시작합니다. 엔딩은 `arc`, `spiral`, `bounce`, `float` 중 무작위로 선택하며 비행 뒤 3초 동안 함께 기뻐합니다.
- 캐릭터 터치 반응, 달 터치 시 화면 어두워짐, 절차적 효과음과 자장가 배경음악을 지원합니다.
- 사자를 터치하면 갈기를 흔들며 작은 소리를 내고 하트를 뿌립니다. 호랑이를 터치하면 폴짝 뛰며 별을 뿌립니다.
- 여우는 큰 귀와 하얀 꼬리 끝이 특징이며, 터치하면 꼬리를 흔들고 하트를 뿌립니다.
- 말레이곰은 짙은 털과 밝은 가슴 무늬, 항상 내민 분홍 혀가 특징입니다. 터치하면 혀를 더 길게 내밀고 흔들며 하트를 뿌립니다.
- 불곰은 갈색 털과 둥근 귀·큰 앞발이 특징이며, 터치하면 앞발을 흔들고 하트를 뿌립니다. 삵은 점박이 털과 고리무늬 꼬리가 특징이며, 터치하면 꼬리를 흔들고 별을 뿌립니다.
- 친구는 두 줄로 배치합니다. 엔딩에서는 확대된 달과 친구의 공간을 쉬기·다시 놀기 패널과 분리하고, 비행과 착륙 위치를 화면 안으로 제한합니다.
- 친구가 늘어나도 잘 보이도록 줄별 인원에 맞춰 크기를 조절하고, 작은 화면에서는 두 줄 사이 간격을 확보합니다.
- 채소 터치 영역을 넓히고 친구의 현재·도착 위치와 다른 채소를 피해 생성합니다. 마지막 채소를 모은 후 추가 수집과 생성을 멈춥니다.
- 오른쪽 위 **잠깐 쉬기** 또는 Escape 키로 움직임·게임 시간·음악을 함께 멈추고, **계속 놀기**로 이어갑니다. 다른 탭으로 이동하면 자동으로 쉬며, 돌아와도 직접 계속하기 전까지 기다립니다.
- 소리 버튼으로 배경음악·효과음·읽어 주기를 함께 켜거나 끕니다. 읽어 주는 동안 음악과 효과음을 낮추고, 쉬기·화면 숨김·처음 화면·엔딩 전환 시 음성도 멈춥니다. 선택은 브라우저 저장소에 보관하며, 저장소를 사용할 수 없어도 현재 놀이에서는 작동합니다.
- 효과음의 겹침과 음량을 줄이고, 파티클을 최대 48개로 제한합니다. 시스템의 움직임 줄이기 설정을 반영하며, 화면 주사율에 따른 효과 속도 차이를 줄였습니다.
- 엔딩에서는 **이제 쉬기**로 처음 화면에 돌아가거나 **다시 놀기**로 친구 순서를 새로 섞습니다. 화면 아무 곳이나 눌러도 재시작하지 않습니다. 주변의 초록색을 찾아보는 화면 밖 놀이도 제안합니다.
- 고해상도 화면은 최대 2배 해상도로 그리며, 터치와 배치는 화면의 CSS 픽셀 좌표를 사용합니다.

Canvas 2D와 Web Audio API를 사용하는 순수 JavaScript 프로젝트입니다. 읽어 주기는 브라우저가 제공하는 Web Speech API의 한국어 음성을 선택적으로 이용합니다. 외부 패키지, 이미지·음원 파일, 빌드 단계는 없습니다.

## 파일과 작업 컨텍스트

| 파일 | 역할 |
|------|------|
| `index.html` | Canvas와 시작·쉬기·엔딩 조작 패널 |
| `style.css` | 전체 화면과 터치 레이아웃 |
| `game.js` | 상태, 렌더링, 오디오, 입력, 엔딩을 담은 단일 IIFE |
| `tests/game-smoke.js` | 의존성 없는 동작 회귀 검사 |
| [PRD.md](PRD.md) | 현재 구현에 맞춘 제품 사양과 아키텍처 |
| [docs/ux-review.md](docs/ux-review.md) | 외부 설계 근거, 적용 내용과 학습효과 검증의 한계 |
| [.continue-here.md](.continue-here.md) | 최근 작업 상태, 검증 범위, 후속 수정 후보 |
| [AGENTS.md](AGENTS.md) | 이후 작업 시 따라야 할 저장소 지침 |

작업을 시작할 때 `AGENTS.md`, 이 문서, `PRD.md`, `.continue-here.md`를 읽습니다. 구현 여부는 `game.js`를 기준으로 확인합니다.

## 검증

저장소 루트에서 Node.js가 있다면 실행합니다.

```sh
node tests/game-smoke.js
```

macOS에서는 별도 설치 없이 JavaScriptCore로 실행할 수도 있습니다.

```sh
/System/Library/Frameworks/JavaScriptCore.framework/Versions/A/Helpers/jsc tests/game-smoke.js
```

회귀 검사는 문법, 엔딩 4종 × 화면 크기 7종의 28개 조합, 친구 12종, 부탁한 종류·수량과 힌트, 쉬기·재개·재시작·화면 회전, 오디오 생명주기·소리 저장 예외, 고해상도 입력·움직임 설정·파티클을 확인합니다. 실행한 버전과 상세 결과는 `.continue-here.md`의 현재 구현 절을 확인합니다. Canvas와 Audio를 모의 API로 실행하는 검사와 실제 브라우저의 화면 검증을 구분하며, 완료한 항목과 남은 제약은 `.continue-here.md`에 기록합니다. 데스크톱 브라우저 검사만으로 iPhone Safari의 실제 음성 재생을 검증한 것으로 보지 않습니다.

외부 자료에 근거해 수량·이름 탐색과 공동 놀이를 돕도록 설계했습니다. 학습효과나 실제 아이의 선호를 검증한 것은 아닙니다.
