# 유아용 놀이 UX 검토

검토일: 2026-11-11

목표는 기존의 다정한 친구와 채소 수집 놀이를 유지하면서, 아이가 자기 속도로 조작하고 수량·이름을 살펴볼 수 있게 하는 것이다. 실패·벌점·시간제한을 추가하지 않는다. 아래는 외부 자료와 코드 검토를 바탕으로 적용한 설계와 후속 관찰 항목이다. 실제 적용 상태는 `game.js`와 `PRD.md`, 실행 검증 결과는 `.continue-here.md`를 기준으로 확인한다.

## 개선 전 코드에서 확인한 문제

- 점수는 작은 숫자와 당근 아이콘만으로 표시되어, 오이를 포함한 실제 수집물과 수량의 관계가 충분히 드러나지 않는다.
- 시작 안내는 글자 한 줄에 의존한다. 시작·종료 문구가 계속 밝아졌다 어두워지며, 엔딩 뒤에는 화면 어디를 눌러도 재시작한다.
- 채소 수집음·먹는 소리·친구 등장 음악이 겹친다. 엔딩의 다수 캐릭터가 매 프레임 파티클을 생성하여 화면 주사율에 따라 효과 밀도도 달라진다.
- 동물이나 채소를 살펴보는 이름 안내와 놀이를 멈추는 조작이 없다.

## 근거와 적용

| 확인한 자료 | 자료가 설명하는 원칙 | 적용 내용 또는 후속 관찰 |
|---|---|---|
| [NAEYC: 유아 수 개념 놀이](https://www.naeyc.org/resources/pubs/tyc/spring2022/number-composition) | 작은 수 1~5, 구체물, 물체 하나와 수 하나의 대응을 이용한다. 발달 속도는 아이마다 다르다. | 도착한 채소의 그림과 숫자를 하나씩 늘리고 우리말 수도 표시한다. 전체 14개를 5·5·4개의 바구니로 나누고, 다섯 개를 채우면 추가로 기다린다. 다음 채소가 도착하면 바구니 이름을 바꿔 새 묶음을 안내한다. |
| [PBS KIDS: Guided Play](https://www.pbs.org/parents/thrive/guided-play-maximizing-kids-learning-and-fun) | 아이가 놀이를 이끌고, 어른은 질문·설명·비교로 탐색을 돕는다. | 수집한 채소의 색·이름과 터치한 동물 이름을 짧게 보여준다. 시작 화면에서 함께 이름을 말하고 천천히 놀도록 안내한다. 정답 검사·벌점·시간제한을 추가하지 않았다. |
| [NAEYC·Fred Rogers 공동 입장문](https://www.naeyc.org/sites/default/files/globally-shared/downloads/PDFs/resources/topics/ps_technology.pdf) | 매체는 의도적으로 선택하며 공동 참여, 실제 경험, 관계를 지원해야 한다. 화면 활동이 다른 놀이를 대체해서는 안 된다. | 일시정지와 명시적인 이제 쉬기·다시 놀기를 제공한다. 엔딩에는 주변의 초록색을 찾는 화면 밖 놀이를 제안한다. 아무 곳이나 눌러 다음 판이 시작되지는 않는다. |
| [W3C: Target Size Enhanced](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) | 작은 표적은 정밀한 터치를 어렵게 한다. 44×44 CSS px 이상의 표적을 설명하며, 더 큰 영역도 권장한다. | 시작·쉬기·계속·다시 놀기를 큰 DOM 버튼으로 제공한다. 시작에는 채소 그림과 짧은 문구를 함께 사용한다. 버튼 간격, 초점 표시와 접근 가능한 이름을 제공한다. |
| [W3C: Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions) 및 [Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html) | 불필요한 움직임을 끌 수 있게 하고, 지속되는 자동 움직임을 제어할 수 있게 한다. | 시작·종료 문구의 지속적인 깜박임을 없애고 시스템의 `prefers-reduced-motion`을 반영한다. 파티클은 최대 48개로 제한하고, 쉬는 동안 게임 시간·움직임·오디오를 함께 멈춘다. 음량과 중복 효과음 축소는 코드 검토와 차분한 경험이라는 목표에 따른 추가 설계 판단이다. |
| [PBS KIDS 공식 플레이테스트](https://www.pbs.org/parents/playtesting) | 아이와 보호자의 반응을 통해 경험을 개선하며, 첫 플레이를 스스로 이해하는지도 관찰한다. | 후속 관찰: 자동·브라우저 검사와 별도로 첫 시작, 첫 채소 수집, 바구니 전환, 이름 탐색, 쉬기를 실제 놀이에서 살펴본다. 보호자는 가까이에서 돕되 처음부터 모든 조작을 대신 설명하지 않는다. 이 사용자 관찰은 아직 실시하지 않았다. |

## 적용과 검증의 범위

수량·그림의 대응, 이름 안내, 큰 조작 버튼, 차분한 효과, 공동 놀이 제안과 시스템의 움직임 줄이기 설정 반영을 구현했다. JavaScriptCore 회귀 검사(엔딩 28개 조합과 새 조작·오디오·시간·표시 검사) 및 실제 WebKit 15개 시나리오를 통과했다. 실행한 범위와 한계는 `.continue-here.md`에 기록한다. 자동·브라우저 검증과 실제 아이의 놀이 관찰을 구분한다.

쉬기는 아이와 보호자가 놀이를 잠시 멈출 수 있는 기능이다. 자동 사용시간 제한이나 보호자 인증 기능을 뜻하지 않는다. 큰 버튼과 움직임 제어도 전체 게임의 WCAG 적합성을 인증하는 것은 아니다.

수 개념·어휘 학습을 돕는 설계 근거와 이 게임의 학습 효과 입증은 구분한다. 학습 효과, 선호도, 실기기 손가락 조작, 실제 음량의 편안함은 아직 검증하지 않았다. NAEYC·Fred Rogers의 2012년 입장문은 공동 놀이와 의도적 사용의 일반 원칙에 참고했으며, 그 문서의 오래된 화면시간 수치를 현재 건강 권고로 적용하지 않는다.
